Custom first-person weapon pictures for the game "150 Days".

Put PNG (or WEBP) files with a transparent background here, named after the weapon kind - the game shows the picture
in the bottom right while that weapon is in hand. No file - the inventory picture is shown.

File names:
  pistol.png         pistol
  smg.png            submachine gun
  rifle.png          hunting rifle, rifle
  shotgun.png        shotgun
  laserPistol.png    laser pistol
  plasmaPistol.png   plasma pistol
  laserRifle.png     laser rifle
  plasmaRifle.png    plasma rifle
  flamer.png         flamer
  minigun.png        minigun
  rocket.png         rocket launcher
  knife.png          knife
  combatKnife.png    combat knife (its own file; if missing - knife.png)
  club.png           club, sledgehammer
  spear.png          spear

Requirements - docs/WEAPON-IMAGES.md.

The pictures (*.png, *.webp) do not go into git (.gitignore): they exist only on this computer.
To add a new one - put it into public/weapons/ in both folders: 150-days and 150-days-opus.
